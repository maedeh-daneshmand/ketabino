# کتابینو | Ketabino

فروشگاه نمایشی کتاب الکترونیکی با رابط فارسی و راست‌چین، ساخته‌شده با Next.js App Router، React، TypeScript و Tailwind CSS.

## اجرا در ویندوز

```powershell
npm.cmd install
npm.cmd run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کن.

برای ساخت و اجرای نسخه تولید:

```powershell
npm.cmd run build
npm.cmd run start
```

## امکانات پیاده‌سازی‌شده

- صفحه اصلی با معرفی کتابینو، دسته‌بندی‌ها، کتاب‌های منتخب و تازه‌ها
- فروشگاه با جست‌وجو، فیلتر دسته‌بندی و زبان، و مرتب‌سازی
- صفحه جزئیات هر کتاب و پیشنهاد کتاب‌های مرتبط
- علاقه‌مندی‌ها و کتابخانه با ذخیره‌سازی در LocalStorage
- اشتراک ماهانه، سه‌ماهه و سالانه به‌صورت نمایشی
- مطالعه نمونه کتاب با جابه‌جایی بین صفحات
- سبد خرید، حذف کتاب و محاسبه جمع سفارش
- تسویه‌حساب نمایشی و انتقال کتاب‌های سفارش به کتابخانه
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## داده‌ها و محدودیت‌های نسخه فعلی

اطلاعات کتاب‌ها در `src/data/books.ts` و دسته‌بندی‌ها در `src/data/categories.ts` نگهداری می‌شوند. جلدهای فعلی به‌صورت گرافیکی و اختصاصی در رابط ساخته می‌شوند. داده‌ها و قیمت‌ها نمونه هستند و برای نمایش امکانات استفاده شده‌اند؛ امتیاز، تعداد نقد یا رتبه فروش ساختگی نمایش داده نمی‌شود.

در این نسخه Backend، پایگاه داده، ورود کاربران، درگاه پرداخت و API خارجی وجود ندارد. وضعیت علاقه‌مندی‌ها، کتابخانه و سبد خرید روی همان مرورگر و با LocalStorage ذخیره می‌شود.

## ساختار مهم پروژه

```text
src/
  app/          مسیرها و صفحات سایت
  components/   اجزای رابط و تعاملات
  data/         داده‌های آزمایشی کتاب و دسته‌بندی
  lib/          ابزارهای ذخیره‌سازی سمت مرورگر
```
